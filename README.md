# AutoDapp

Built with [Next.js](https://nextjs.org/) and TypeScript, configured for
static export (`output: "export"` in `next.config.ts`).

## Development

```bash
pnpm install
pnpm run dev
```

## Build

```bash
pnpm run build
```

Writes a static site to `./out`, deployable to any static host. Preview
the export locally with:

```bash
pnpm run start
```
